# 點解要呢個檔：
#   Material 嘅搜尋一裝咗 jieba 就會自動用佢分詞，但 jieba 嘅預設詞典係
#   普通話通用語料。落到呢個網站，佢會將「投資」切成「投｜資」、
#   「時候」切成「時｜候」，而「再平衡」「序列風險」呢啲術語根本切唔出。
#   結果就係讀者搵「再平衡」乜都搵唔到。
#
#   呢度只收**真術語**，唔收句子。試過由標題自動抽詞，抽到「一手買齊全世」
#   呢類斷句 —— 垃圾長詞會令 jieba 貪心配對，越搞越差。少而準好過多而雜。
#
# 格式：詞 詞頻。詞頻設高，令 jieba 優先當佢係一個詞。
