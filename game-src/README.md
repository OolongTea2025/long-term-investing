# 烏龍茶的投資人生

一個關於認知偏誤嘅互動故事。七十個決定、二十年、一個乜都冇做嘅對照組。
**三語**：廣東話（原文）／繁體中文／English。

你三十歲，有 $300,000，每季儲到啲錢。有個叫 **Mike** 嘅人同你一齊開始 ——
佢第一日買晒指數基金，之後每季照供，二十年冇再做過任何嘢。

## 點玩

呢個 folder **淨係放源碼同工具**，唔會俾 mkdocs publish 上網。
真正出街嗰份係 build 出去 `../docs/game/`：

```
docs/game/index.html     ← node build.mjs 出嚟嘅
docs/game/assets/        ← 立繪 / 背景 / CG（3.9MB，全世界只有一份）
docs/遊戲.md             ← 網站上面嘅介紹頁（nav 指住呢度）
```

本機試玩：

```bash
python -m mkdocs build
cd site && python -m http.server 8766
# 然後開 http://127.0.0.1:8766/game/
```

- 滑鼠點擊，或者鍵盤 `A`–`E` 揀選項
- `Enter` / `Space` 繼續
- 右上角 `☰` 睇返自己所有決定，`⚙` 改語言／文字速度／音效／偏誤標籤
- 語言亦都可以用網址指定：`?lang=zh-HK` / `?lang=zh-TW` / `?lang=en`
  （次序係 網址 > 上次揀過嗰個 > 廣東話；**刻意唔睇** `navigator.language`）
- 打字途中點一下文字框可以跳過

## 設計原則：唔准有「暗中扣分」

呢個係重寫版最重要嘅一件事。

**舊版有個隱藏機制**：你嘅「自我」數值越高，每回合回報就直接被扣得越多；
「紀律」越高就直接加。即係話，遊戲喺數學上寫死咗「自我 = 蝕錢」，
然後再用結局話你知「你輸係因為你自我」—— 呢個係循環論證，
教唔到任何嘢，而且對一個成日叫人「睇清楚機制」嘅教學網嚟講，係唔誠實。

**新版冇咗呢啲嘢。** 自我同紀律淨係敘事計數，唔會直接加減回報。
你蝕嘅每一蚊，都一定追溯得返去一個具體機制：

| 機制 | 點樣蝕 | 教學網邊一章 |
|---|---|---|
| 交易成本 | 佣金 + 印花稅 + 價差，每次買賣 0.28% | 第 2 章 費用蠶食 |
| 唔喺市場 | 你沽咗貨嗰啲回合，升跌都冇你份 | 第 2 章 錯過最好嘅日子 |
| 集中持倉 | 個股中位數效應 + 爆地雷嘅尾部風險 | 第 3 章 分散 / 99-01 |
| 槓桿 | 孖展利息 + 被強制平倉嘅滑點 | 第 7 章 槓桿 |
| 人工增長 | 事業選擇令你儲蓄複利快咗／慢咗 | 第 7 章 人力資本 |

### 集中持倉點解會蝕

唔係「指數但波幅大啲」。指數嘅回報係由一小撮股票拉起 ——
單一股票嘅**平均數**同指數一樣，但**中位數低過指數**。
所以個股衝擊用平均值為 0 嘅對數常態模擬，佢嘅中位數自然係負數。
呢個就係第 3 章講嘅 99/01 效應，照字面寫入模型。

### 唯一一條唔靠運氣嘅跑贏路

完美紀律 = 同 Mike 打成平手（你就係佢）。
喺呢個模型入面，唯一可以**穩定**跑贏指數而唔使賭嘅方法，
係**人工加得快、儲多啲錢**。集中同槓桿都可以令你贏，但期望值係負。

呢個唔係為咗做戲砌出嚟嘅，係模型自己跑出嚟嘅結果 —— 亦都啱啱好係
第 7 章（人力資本）同附錄 B（開源）嘅結論。

## 結局點判

打完之後遊戲會做兩件事。

**一、逐項移除歸因。**
攞返你今次玩嗰條一模一樣嘅市場路徑、同你一模一樣嘅七十個決定，
每次淨係熄咗其中一樣機制再重跑一次。分別就係嗰樣嘢嘅代價，以港元計。

因為用同一條路徑，呢個數字係精確嘅，唔係估。
（五項加埋唔會啱啱好等於總差距 —— 佢哋互相影響，遊戲入面有講明。）

**二、Monte Carlo 分運氣同實力。**
攞你實際做過嘅七十個決定，原封不動擺去 400 個全新嘅市場歷史度重跑。
同一套行為、唔同嘅市場。

- 大部分時空都跑贏 → **真 Alpha**
- 淨係今次贏 → **幸運兒**（遊戲會用直方圖畀你睇，你今次排第幾百分位）

實測：一個靠集中同槓桿贏咗嘅玩家，MC 跑贏率大約 25%；
一個靠紀律 + 事業贏嘅玩家，MC 跑贏率接近 100%。分得好清楚。

**八個結局**：出局 / 爆倉 / 韭菜的一生 / 溫水煮蛙 / 醒覺 / 無為 / 真 Alpha / 幸運兒

其中「**無為**」係新加嘅，亦都係最難攞：你嘅結果同 Mike 幾乎一樣。
呢個唔係打和，呢個就係目標本身。

## 平衡驗證

`node build.mjs && node test.mjs 1200` —— 每種玩法真係試玩 1200 局：

| 玩法 | 跑贏 Mike | 中位比率 | 中位終值 | 爆倉率 | 中位成本 |
|---|---|---|---|---|---|
| 最佳玩法（定額+指數+顧住份工） | 62.7% | 1.01 | $3,940,742 | 0.0% | $44,177 |
| 三成偏誤 | 25.0% | 0.73 | $2,649,285 | 1.3% | $402,828 |
| 五成偏誤 | 21.2% | 0.52 | $2,015,437 | 4.5% | $516,247 |
| 七成偏誤 | 18.0% | 0.33 | $1,264,506 | 8.5% | $567,387 |
| 全部揀偏誤選項 | 12.5% | 0.18 | $697,255 | 11.0% | $960,258 |
| 最自毀（次次揀最癲） | 8.3% | 0.05 | $97,298 | 49.8% | $483,032 |

重點係**梯度平滑**：醒目一成就好一截。
舊版唔係咁 —— 舊版嘅七成偏誤同十成偏誤結果幾乎一樣（都係爆倉），
即係話「醒目啲」冇獎勵，個遊戲實際上喺度講「你點做都冇用」。
呢個唔止係壞遊戲設計，仲同教學網想講嘅嘢啱啱相反。

市場模型：regime-switching GBM，年化 7.1%、波幅 15.5%，
二十年入面中位最大回撤 −40%。

## 測試

```bash
node build.mjs         # src/ -> index.html（同時出 src/game.gen.mjs 畀測試用）
node test.mjs 1200     # 試玩平衡 + 歸因 + 結局分佈 + 場景完整性
node i18ncheck.mjs     # 譯文覆蓋率 + 佔位符 + HTML tag + 語言純度
node domtest.mjs       # 喺最小 DOM 度由標題撳到結局，捉 runtime error + 存檔來回
node domtest.mjs zh-TW # 同上，但行台灣版（en 亦然）—— 每個語言都要行一次
```

`domtest.mjs` 會驗證存檔／讀檔完全一致。新存檔格式只存
**seed + 決定序列**（7.3 KB），讀檔時用 seed 重生成市場、再重播決定 ——
所以淨值、成本、集中度、槓桿、偏誤數全部一模一樣，唔會走樣。

## 技術

- 單一 HTML 檔（111 KB）+ 37 張 WebP（3.9 MB）
- 零外部依賴、零 CDN
- Web Audio API 程序生成 BGM 同音效，lookahead scheduler 對齊 `ctx.currentTime`，
  三個階段各有自己嘅和弦進行（大調 → 三全音 → 空心五度）
- Canvas 2D 畫走勢圖同 Monte Carlo 直方圖
- 版面用 `100dvh` grid，直度手機唔會被瀏覽器工具列切走
- 跟 `prefers-reduced-motion`

## 放上教學網

遊戲入面所有返教學網嘅連結，都假設佢擺喺網站嘅 `/game/` 之下
（用 `../新手篇/...` 相對路徑）。**台灣版同英文版係 `../zh-TW/...` / `../en/...`**，
由 `lang/*.js` 嘅 `ch{}` 覆蓋 —— 檔名喺三個語言都保持廣東話，呢個係網站嘅既定決定。
用 `file://` 直接開嘅話，`HAS_SITE` 會自動變 false，啲連結會收起，遊戲照玩。

已經做咗：擺入 `docs/game/`、三個介紹頁（`docs/遊戲.md` / `.zh-TW.md` / `.en.md`）+ nav entry、
第 6 章結尾入口、`target="_blank"`（避開 Material 嘅 `navigation.instant`）、
附錄 C 加咗 AI 立繪聲明。**三個介紹頁嘅「開始玩」連結都明寫 `?lang=`**
（連廣東話嗰版都要寫 `?lang=zh-HK`），否則一個試過換語言嘅讀者，
下次由廣東話版撳入去會跌返落佢上次揀嗰種語言。

`resume.js` 唔使改 —— mkdocs 只會將 `extra_javascript` 注入由 .md render 出嚟嘅頁，
`docs/game/index.html` 係原封 copy 嘅靜態檔，載唔到 resume.js，
所以 `/game/` 永遠唔會被記做「上次嗰頁」。
