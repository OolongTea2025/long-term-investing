# D　行為金融學 & 市場異象 —— 人點樣系統性咁犯錯

!!! who "呢章適合邊個"
    **🔴 進階選讀 · 硬核理論**<span class="lvtag">選讀</span>
    A 章講「市場理論上有效」，但 C 章成日提到「行為偏差」。呢章補上另一半：**人腦有一堆系統性偏誤，令市場價格會偏離價值**。同時解答一個經典問題 —— 既然有錯誤定價，點解聰明錢唔即刻套利抹平佢？

!!! tip "一句講晒"
    傳統金融假設「人理性」，但**行為金融學**證明人喺**預期、風險偏好、認知**三方面都會系統性犯錯。加上**套利限制**（基本面風險、噪聲交易者風險、實施成本），聰明錢冇法充分套利 → **價格可以長期偏離價值**。結論（Statman「行為有效市場」）：**「價格 = 價值」多數唔成立，但「市場好難打敗」依然成立。**

---

## 一、行為金融學挑戰咩？

傳統金融學建基於兩大假設：**人有理性預期**、**按預期效用最大化做決策**。由此引申出三個要素 —— 行為金融學逐個挑戰：

!!! note "三個被挑戰嘅要素"
    | 傳統假設 | 行為金融學嘅挑戰 |
    |---|---|
    | **理性預期** | 人嘅預期唔完全理性，有過度自信、錨定等偏差 |
    | **及時處理全部資訊** | 認知研究證明人腦處理能力**有限**，做唔到 |
    | **完全理性嘅風險偏好** | 面對不確定時難以理性；有前景理論、模糊厭惡 |

## 二、套利限制：點解錯誤定價唔會即刻消失？

呢個係最關鍵嘅一問。就算有錯誤定價，理論上聰明錢應該即刻套利、抹平佢 —— 但現實唔係咁。

!!! example "神戶大地震（1995）—— 市場唔係即時理性"
    1995 年 1 月 17 日，日本神戶發生 7.3 級大地震。**地震當日東京股市只係輕微跌**；要一個星期後，市場先真正反映影響 —— 到 1 月 23 日日經跌 5.6%，地震後 10 日累跌約 8%。

    仲離奇嘅係：日經大跌嗰日，**倫敦 FTSE 跌 1.4%、巴黎 CAC 跌 2.2%、德國 DAX 跌 1.8%、巴西阿根廷跌約 3%** —— 呢啲國家根本冇受地震直接影響。呢啲價格變動**唔可能純粹來自理性行為**，證明資訊嘅傳遞同消化**需要時間**、市場相互關聯。

!!! note "噪聲交易者模型 + 三種套利限制"
    行為金融學認為市場由**理性投資者**同**噪聲交易者（韭菜）**構成。但理性投資者冇法充分利用錯誤定價，因為有**套利限制**：

    1. **基本面風險**：套利倉可能因基本面惡化而蝕。
    2. **噪聲交易者風險**：非理性可以持續更耐，套利者可能未等到價格回歸就先爆。
    3. **實施成本**：交易成本、賣空限制等。

    所以錯誤定價**可以持續**，唔會即刻被抹平。

## 三、偏誤地圖：人腦嘅三類系統性錯誤

（呢啲同新手篇第 6 章嘅「12 個陷阱」互相呼應，但呢度係**理論分類**版。）

### （1）預期中嘅偏差

!!! example "評估未來時嘅偏誤"
    - **過度自信**：對自己判斷過度自信 → 解釋咗市場每日大量交易。
    - **樂觀主義**：天生樂觀，被「控制幻覺」放大。
    - **代表性啟發**：靠「相似程度」判斷，忽略基礎機率。
    - **保守主義**：一旦形成觀點就拒絕更新，改變好慢。
    - **確認偏誤**：選擇性回憶／搜集有利資訊，忽略矛盾證據。
    - **錨定效應**：過度依賴最初嘅資訊（「錨」），即使佢無關。
    - **可得性啟發**：靠「最易諗起」嘅例子做判斷。

### （2）風險偏好中嘅偏差

!!! note "面對不確定時嘅偏誤"
    - **前景理論**（Kahneman & Tversky）：描述人喺不確定下點決策；核心係**價值函數**（對得失嘅評估，損失比等額收益更痛）同**權重函數**（對機率嘅扭曲，高估細機率）。
    - **模糊厭惡**：當結果分佈未知，人傾向揀「熟悉」嘅選項；但因為過度樂觀同確認偏誤，人往往喺「自以為熟悉」嘅領域**輸得更慘**。

### （3）認知限制

!!! note "處理能力嘅先天局限"
    - **有限注意力**：人腦處理能力有限，只應對最顯著資訊。（例如一則舊消息俾大眾媒體廣泛報導，投資者先突然關注。）
    - **分類思維**：將資產分類簡化思考 → 判斷時只睇「類別」唔睇個別基本面。（例如一隻股被納入某指數，價格就開始同指數其他成份股一齊郁。）

## 四、偏誤點樣造成「市場異象」

!!! example "由偏誤到異象"
    - **盈餘慣性（PEAD）**：因有限注意力，人對新基本面反應不足 → 價格喺業績公告後**繼續漂移**。（消息喺星期五出，漂移更明顯。）
    - **投資者情緒模型**：受保守主義同代表性啟發影響 → 造成動量、價值等異象。
    - **私有資訊過度自信**：深入研究後過度自信 + 確認偏誤忽略反面 → 造成動量、盈餘動量。
    - **反應不足 / 反應過度**：基本面交易者同動量交易者互動 → 短期反應不足（動量獲利），大量動量者採用同一策略 → 最終過度反應同反轉。
    - **彩票股（收益率右偏）**：人放大尾部機率 → 過度追逐右偏（「可能中大獎」）嘅股 → 推高價、**降低未來回報**。
    - **處置效應**：升嘅股拿唔住（快手獲利），跌嘅股捨唔得走（博返本）—— 同損失厭惡有關。

## 五、行為有效市場：兩個講法要分清

!!! quote "Statman 嘅「行為有效市場」"
    有效市場假說其實包含**兩層**意思，要分清：

    1. **「價格 = 價值」** —— 因為行為偏差 + 套利限制，價格**可以偏離價值而唔被修正** → 呢層**通常唔成立**。
    2. **「市場難以被戰勝」** —— 對只掌握公開資訊嘅普通投資者嚟講 → 呢層**依然成立**。

    **關鍵洞見**：「天下冇免費午餐」（難打敗市場）**唔等於**「價格 = 價值」。即使喺無效市場，「冇免費午餐」一樣成立，但**唔可以**由此反推「價格 = 價值」。

    > Fischer Black 講得好：噪聲令市場不夠有效，但**同時亦阻止咗人利用呢種無效性** —— 呢句係「行為有效市場」最好嘅總結。

## 六、真異象、假異象：三種可能

發現一個「能預測回報」嘅變量，背後可能係三種原因 —— **分清好重要**：

!!! note "風險補償 vs 錯誤定價 vs 資料窺探"
    1. **風險補償**：高回報股孭咗更高系統性風險 → 回報係補償。（可用資產定價模型嘅 β 檢驗。）
    2. **錯誤定價**：組合建構後累積收益持續上升 → 反映價格緩慢吸收資訊嘅「價格發現」過程。
    3. **資料窺探（data snooping / 過擬合）**：太多人用同一批數據試太多變量 → 被發表嘅「顯著異象」註定喺**樣本內**靚，但**樣本外**可能係假。

!!! warning "點分真假？用樣本外數據"
    因為發表偏差同資料窺探偏差好嚴重，單靠「提高 t 值門檻」作用有限。**用全新嘅樣本外數據去核對，先係排除虛假因子最好嘅辦法。** ← 呢個係第 10 章「因子會樣本外失效」嘅理論根據。

## 七、投資者情緒

!!! note "情緒作為綜合指標"
    **投資者情緒**反映唔同偏差對預期回報嘅綜合影響：

    - 情緒高漲時：**難估值、難套利嘅股會被高估**，伴隨更低嘅未來回報。
    - 情緒低迷時：投機性股反而表現更好；市場呈現顯著嘅**高風險高回報**特徵。
    - 情緒高漲時：市場預期超額回報同風險**唔再相關**（風險補償失靈）。

    呼應第 9 章 Marks：**「人人都覺得冇風險」嗰陣（情緒最高漲），先最危險。**

## 小結

- 行為金融學挑戰「人理性」：喺**預期、風險偏好、認知**三方面都系統性犯錯。
- **套利限制**（基本面風險／噪聲交易者風險／實施成本）令錯誤定價**唔會即刻消失**（神戶地震為例）。
- 偏誤三類：預期（過度自信、錨定、確認……）／風險偏好（前景理論、模糊厭惡）／認知（有限注意力、分類思維）。
- 偏誤造成異象：PEAD、動量、彩票股、處置效應等。
- **行為有效市場**（Statman）：「價格=價值」多數唔成立，但「市場難打敗」成立；**冇免費午餐 ≠ 價格=價值**。
- 真假異象：風險補償／錯誤定價／資料窺探 —— **用樣本外數據驗證**。
- 情緒最高漲時最危險（呼應 Marks）。
