# 附錄 B　窮人怎麼投資 —— 資源愈少，愈要用對方法

!!! who "這章適合誰"
    **Level 1–2（本金小、每個月都很緊）· 特別想跟你講**<span class="lvtag">L1–L2</span>
    如果你覺得「投資是有錢人才玩得起的」、「我只有這麼一點錢，投資幹嘛」—— 這篇就是寫給你的。不是雞湯，是講清楚**為什麼本金小的人，反而最不應該亂來。**

!!! tip "一句話講完"
    窮不是不能投資，而是**沒有本錢輸**。正因為這樣，窮人愈應該挑**最省心力、最不用猜、最難出錯**的方法 —— 也就是定期定額買全市場 ETF。花俏的東西是留給輸得起的人玩的，不是你。

---

## 一、「稀缺」怎麼偷走你的判斷力

先講一個很重要、但很少人講的事實：**窮不只是錢包的問題，還會影響你的腦袋。**

學術界（Mullainathan & Shafir 的《Scarcity 稀缺》研究）發現：當一個人長期為錢煩惱、心力被生活壓力佔滿，他的**認知頻寬（bandwidth）會被吃掉**，剩下的專注力跟自控力就變少了。結果：

!!! note "稀缺造成的惡性循環"
    - **認知受限**：沒時間、沒精力去消化投資資訊，容易信錯人、挑錯東西。
    - **自控力受限**：心智資源被生活的困難佔用，愈容易追求即時滿足 → 追高殺低、賭一把翻身。
    - **後果放大**：本金小，一次大錯（All-in 一支股票、踩到雷的商品）可能就傷到回不了頭。

    於是：**愈窮 → 愈容易做錯投資決定 → 愈窮。** 這個循環不是因為窮人笨，而是環境本身就對你不利。

明白這一點很重要 —— 因為**破解的方法，就是挑一個「不需要你有很多心力也做得好」的投資方式。**

---

## 二、為什麼被動指數是本金小的人最好的出路

被動指數投資（定期定額買 VT 這類全市場 ETF）適合窮人，不是隨口說說，而是它**剛好對應回上面那三個限制**：

| 稀缺造成的限制 | 被動指數為什麼適合 |
|---|---|
| 沒有多餘資金 | **有多少、買多少**：不用一大筆，每個月的閒錢定期定額投入，靠時間跟複利滾。 |
| 沒時間／知識 | **不用研究個股**：挑一檔全市場 ETF，長期抱著，不用看財報、不用看盤。 |
| 情緒容易失控 | **不用判斷時機**：訂好計畫、定期定額買、下跌也照買，不靠意志力硬撐。 |

!!! quote "核心一句"
    有錢人可以用錢試錯、請人打理、輸得起去拚；**你沒有這個本錢，所以你更要用一個「不靠運氣、不靠天分、不靠情緒」也行得通的方法。** 被動指數就是為這種人而設計的。

## 三、本金小，優先順序跟有錢人不一樣

同樣一句「開始投資」，本金小的人要**把順序倒過來**。不要一看到「投資」兩個字就衝去開戶買東西 —— 先搞定以下幾件事，才是真的幫得了你。

!!! example "窮人版投資優先順序（由上到下做）"
    1. **還清高利率的債**：卡債、信用貸款那些動輒 20%–30% 的利息。**還清它 = 穩賺 20%–30%**，沒有任何投資比這個更穩。還清之前，不要談投資。
    2. **存好緊急預備金**：至少半年生活費，放在領得出來、又不會虧本的地方（定存／貨幣型基金）。**沒有緊急預備金就去投資，一遇到失業／急事，就得在最差的時機賣股變現** → 從「暫時的波動」變成「永久的損失」。
    3. **開源 > 省到極致**：本金小的時候，**你的人力資本（賺錢能力）才是你最大的資產**。花時間提升收入、學技能，報酬遠高於你省下的那幾塊、或者在股市拚的那幾趴。
    4. **先固定，後投資**：搞定以上三件事，才把**每個月固定的一筆閒錢**定期定額買 VT。

!!! warning "最重要的一點"
    本金小，代表你**沒有試錯空間**。所以窮人反而**最不應該**去玩：個股、槓桿、選擇權、來歷不明的「高報酬」商品、或者「一把翻身」的賭博式操作。這些東西輸一次的代價，對你來說太大了。**愈窮，愈要無聊、愈要穩、愈要簡單。**

## 四、時間，是窮人唯一跟有錢人平等的資產

你沒有有錢人那麼多本金，但有一樣東西**大家一天都只有 24 小時、一年都只有 365 天** —— 就是**時間**。而長期投資最強的引擎，正好是時間帶來的**複利**。

> 本金小沒關係，**早開始 + 不中斷 + 夠久**，複利會幫你慢慢追上來。真正輸的，不是「本金小」，而是「**因為本金小所以覺得沒用，乾脆不開始**」，或者「中途賭一把輸光出場」。

!!! tip "所以，窮人版的致勝方程式很簡單"
    **搞定債務跟緊急預備金 → 努力提升收入 → 每個月固定一筆買 VT → 不要亂動 → 交給時間。**

    無聊到爆，但這正好就是最適合你、最難輸的方法。

## 小結

- 窮不只是錢包的問題，**稀缺會偷走你的專注力跟自控力**，讓人更容易做錯投資決定。
- 破解的方法：挑一個**不靠運氣、不靠天分、不靠情緒**也行得通的方式 —— 被動指數。
- 本金小的優先順序：**還高利率的債 → 存緊急預備金 → 開源提升收入 → 才定期定額買 VT**。
- 愈窮愈要**無聊、穩、簡單**；花俏跟槓桿是留給輸得起的人的。
- **時間 + 複利**是你跟有錢人最平等的資產 —— 早開始、不中斷，最重要。
