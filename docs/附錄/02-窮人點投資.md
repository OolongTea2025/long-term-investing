# 附錄 B　窮人點投資 —— 資源越少，越要用啱方法

!!! who "呢章適合邊個"
    **Level 1–2（本金細、月月緊）· 特別想同你講**<span class="lvtag">L1–L2</span>
    如果你覺得「投資係有錢人先玩得起」、「我得咁少錢投資嚟做乜」—— 呢篇就係寫俾你。唔係雞湯，係講清楚**點解本金細嘅人，反而最唔應該亂嚟。**

!!! tip "一句講晒"
    窮唔係唔可以投資，而係**冇本錢輸**。正因為咁，窮人越應該揀**最慳心力、最唔使估、最難出錯**嘅方法 —— 即係定期定額買全市場 ETF。花巧嘅嘢係留俾輸得起嘅人玩，唔係你。

## 一、「稀缺」點樣偷走你嘅判斷力

先講一個好重要、但好少人講嘅事實：**窮唔單止係銀包嘅問題，仲會影響個腦。**

學術界（Mullainathan & Shafir 嘅《Scarcity 稀缺》研究）發現：當一個人長期為錢煩、心力被生活壓力佔滿，佢嘅**認知頻寬（bandwidth）會被吃掉**，剩返嘅專注力同自控力就少咗。結果：

!!! note "稀缺造成嘅惡性循環"
    - **認知受限**：冇時間、冇精力去消化投資資訊，容易信錯人、揀錯嘢。
    - **自控力受限**：心智資源被生活困難佔用，越易追求即時滿足 → 追高殺低、賭一鋪翻身。
    - **後果放大**：本金細，一次大錯（All-in 一隻股、中伏產品）可能就傷到返唔到轉頭。

    於是：**越窮 → 越易做錯投資決定 → 越窮。** 呢個循環唔係因為窮人蠢，而係環境本身就對你不利。

## 二、點解被動指數係本金細嘅人最好嘅出路

被動指數投資（定額買 VT 呢類全市場 ETF）啱窮人，唔係啱心口噏，而係佢**啱啱好對應返上面三個限制**：

| 稀缺造成嘅限制 | 被動指數點解啱 |
|---|---|
| 冇多餘資金 | **有幾多、買幾多**：唔使一大舊，每月閒錢定額投入，靠時間同複利滾。 |
| 冇時間 / 知識 | **唔使研究個股**：揀一隻全市場 ETF，長期揸，唔使睇財報、睇即市。 |
| 情緒容易失控 | **唔使判斷時機**：定好計劃、定額買、跌市都照買，唔靠意志力頂。 |

!!! quote "核心一句"
    有錢人可以用錢試錯、請人打理、輸得起去搏；**你冇呢個本錢，所以你更加要用一個「唔靠彩數、唔靠天份、唔靠情緒」都行得通嘅方法。** 被動指數就係為咗呢種人而設。

## 三、本金細，優先次序同有錢人唔同

同一句「開始投資」，本金細嘅人要**倒返轉個次序**。唔好一見到「投資」兩隻字就衝去開戶買嘢 —— 先搞掂以下幾樣，先至真係幫到你。

!!! example "窮人版投資優先次序（由上到下做）"
    1. **還清高息債**：卡數、私人貸款嗰啲動輒 20%–30% 息。**還清佢 = 穩賺 20%–30%**，冇任何投資穩定過呢個。未還清之前，唔好講投資。
    2. **儲起應急金**：3–6 個月生活費（收入唔穩定、或者係散工嘅，就儲足 6 個月），擺喺提得到、唔會蝕本嘅地方（定存 / 貨幣基金）。**冇應急金就投資，一撞到失業／急事，就要喺最差時機沽貨套現** → 由「暫時波動」變「永久損失」。
    3. **開源 > 慳到盡**：本金細嗰陣，**你嘅人力資本（搵錢能力）先係你最大嘅資產**。花時間提升收入、學技能，回報遠高過你慳嗰幾舊、或者喺股市博嗰幾巴仙。
    4. **先固定，後投資**：搞掂以上三樣，先至將**每月固定一筆閒錢**定額買 VT。

!!! warning "最緊要記住"
    本金細，代表你**冇試錯空間**。所以窮人反而**最唔應該**去玩：個股、槓桿、期權、來歷不明嘅「高回報」產品、或者「一鋪翻身」嘅賭博式操作。呢啲嘢輸一次嘅代價，對你嚟講太大。**越窮，越要悶、越要穩、越要簡單。**

## 四、時間，係窮人唯一同有錢人平等嘅資產

你冇有錢人咁多本金，但有一樣嘢**大家一日都係得 24 個鐘、一年都係得 365 日** —— 就係**時間**。而長線投資最強嘅引擎，正正係時間帶嚟嘅**複利**。

> 本金細唔緊要，**早開始 + 唔中斷 + 夠耐**，複利會幫你慢慢追返上嚟。真正輸嘅，唔係「本金細」，而係「**因為本金細所以覺得冇用，索性唔開始**」，或者「中途博一鋪輸清離場」。

想見到「早開始」實際上等於幾多錢：[⏳ 你最大嘅本金，係時間](../時間.md)嗰版有三張圖同一個你自己揸嘅模擬器，兩分鐘睇完。

!!! tip "所以，窮人版嘅致勝方程式好簡單"
    **搞掂債同應急金 → 努力提升收入 → 每月固定一筆買 VT → 唔好郁 → 交畀時間。**

    悶到爆，但呢個正正就係最適合你、最難輸嘅方法。

## 小結

- 窮唔止係銀包問題，**稀缺會偷走你嘅專注力同自控力**，令人更易做錯投資決定。
- 破解方法：揀一個**唔靠彩數、唔靠天份、唔靠情緒**都行得通嘅方式 —— 被動指數。
- 本金細嘅優先次序：**還高息債 → 儲應急金 → 開源提升收入 → 先至定額買 VT**。
- 越窮越要**悶、穩、簡單**；花巧同槓桿係留俾輸得起嘅人。
- **時間 + 複利**係你同有錢人最平等嘅資產 —— 早開始、唔中斷，最緊要。
